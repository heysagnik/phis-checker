# Phis-Checker

Phis-Checker is a tool for malicious URL detection powered by Virus Total.


## Installation

1. **Clone the Repository:**

    ```
    git clone https://github.com/heysagnik/phis-checker.git
    ```

2. **Navigate to the Project Directory:**

    ```
    cd phis-checker
    ```

3. **Install Dependencies:**

    For example, if using Node.js:

    ```
    npm install
    ```

## Usage

Run the checker via the command line:

```
node index.js
```

Alternatively, incorporate it into your workflow by following the documentation provided in the `/docs` folder.
